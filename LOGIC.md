# Логика теста «Мой пьёс» — калибровка v3

## Что подключено

- 17 обязательных экранов из `quiz-config-v3.json`.
- Отдельные шкалы отношения к гостям (`strangerFriendliness`) и сторожевого поведения (`guarding`).
- `dogSociability` сопоставляется как минимальное требование: более социальная собака не штрафуется.
- «Не знаю» не становится ответом `3/5`: значение не передаётся в score, а confidence для него равен `0.25`.
- До трёх forced-уточнений по линьке, слюням и физической силе, если они выбраны как стоп‑факторы.
- До трёх dealbreaker’ов; каждый усиливает вес соответствующего критерия в `2.5` раза.

## Движок v3

`quiz-calculator.js` — browser-порт из переданного `scoring-engine-v3.ts`:

- нормализует породные характеристики по фиксированным `TRAIT_RANGES`;
- использует minimum / maximum / target / asymmetric matching;
- применяет critical caps для тяжёлых конфликтов;
- агрегирует FCI-группы по лучшим уникальным breedFamily с весами `65 / 25 / 10`;
- возвращает `fitLabel` и `resultConfidence`;
- не содержит `cost`.

Контрольные проверки находятся в `scoring-engine.test.js`.

## Результаты калибровки

По stress-test v3 средний разрыв между первой и второй FCI-группой — `3.927`; близких результатов с gap `<4` — `56 из 100`. Это нормальное состояние, его не нужно искусственно раздвигать в интерфейсе. Для слабого совпадения (`<70`) показывается честная формулировка о наименее конфликтном варианте.

## База пород

`data/breed-profiles.researched-v2.json` содержит 110 профилей пород (105 участвуют в расчёте) и 19 шкал v3 с коэффициентами уверенности. При запуске она загружается до начала теста; из `profiles` формируется `window.BREED_PROFILES`, затем приложение вызывает `DogScoring.scoreBreed()` → `aggregateFciGroups()`.

В базе нет фотографий пород: до добавления отдельной карты изображений карточки используют нейтральную локальную фотографию как временную заглушку.
